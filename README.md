# Wild Rift Draft AI PWA

A phone-first installable web app.

## Run locally
Serve this folder over HTTP/HTTPS (service workers do not work from `file://`).
For example: `python -m http.server 8000`, then open `http://localhost:8000`.

## Install on Android
Open the hosted app in Chrome → menu → Add to Home screen / Install app.
